# 聴くAI レポート データ抽出ツール

ブロードリスニングサービス「聴くAI」で公開されているレポートから、次のデータを取り出して確認するためのツール群です。

- プロットに使われている意見（arguments）の全件
- 各レベルのクラスタ（ID、見出し、説明、件数）
- 「みんなの声」の声と、声に付いたコメント（同様の声・返信）の全件
- 「みんなの声」ページ上で、各声・コメントの横に対応する意見を並べて表示する Chrome 拡張
- レポートのグラフ（散布図・階層）上で、意見をテキスト・`arg_id`・`comment_id` で探してハイライトするブックマークレット

> **非公式ツールです。** 聴くAI の運営者、およびレポートを公開している自治体とは関係ありません。サイトの構造が変わると動かなくなることがあります。

## 構成

```
extension/kikuai-args-viewer/   Chrome 拡張（みんなの声ビューア）
scripts/extract-arguments.js    プロットの意見を TSV で取得（コンソール用）
scripts/extract-clusters.js     クラスタを TSV で取得（コンソール用）
scripts/extract-voices.js       みんなの声（声とコメント）を TSV で取得（コンソール用）
bookmarklet/reveal-points.js    プロット上の意見を検索してハイライト（ブックマークレット）
docs/how-it-works.md            データの所在を特定した手順の記録
```

取得したデータ（TSV）はこのリポジトリには含めていません。各自で取得してください。`.gitignore` で `*.tsv` を除外しています。

## 利用上の注意

- 対象サイトの利用規約を確認し、その範囲で利用してください。
- 取得したデータには市民の意見が含まれます。再配布や二次利用は、レポートの公開元の方針に従ってください。
- スクリプトはブラウザに表示済みのページの中身を読むだけで、外部への送信は行いません。拡張機能も、取り込んだ TSV（arguments と clusters）をブラウザ内（`chrome.storage.local`）に保存するだけです。
- `extract-voices.js` だけは、「みんなの声」の 2 ページ目以降を読むために、開いているのと同じサイトのページを順に取得します（ページ数の分だけリクエストが発生します）。取得したデータはブラウザ内でファイルにするだけで、外部には送りません。
- ブックマークレットも、表示中のページの中身を読んで画面に表示するだけです。

## 1. データの取得（arguments / clusters）

レポートのプロットは、公開ページに入れ子の iframe で埋め込まれています。スクリプトは**一番内側のレポート本体のページ**で実行する必要があります。

### 1-1. レポート本体のページを開く

1. 公開ページ（例: `https://maniken.jp/kikuai-open/<レポート名>/`）を開きます。
2. DevTools のコンソールで次を実行し、レポート本体の URL を表示します。

   ```js
   const d = document.querySelector('iframe[src*="kikuai-report-embed"]').contentDocument;
   console.log(d.querySelector('iframe').src);
   ```

3. 表示された URL（`https://kikuai.maniken.jp/<ID>?exp=...&sig=...` の形）を新しいタブで開きます。

> この URL には有効期限付きの署名（`exp`、`sig`）が付いています。期限が切れたら公開ページからもう一度取得してください。Issue や README などに URL をそのまま貼らないでください。

### 1-2. スクリプトを実行する

レポート本体のタブで DevTools のコンソールを開き、`scripts/` のファイルの中身を貼り付けて実行します。

| スクリプト | 出力ファイル | 列 |
|---|---|---|
| `extract-arguments.js` | `report_arguments_YYYYMMDD_HHMM.tsv` | `arg_id`, `argument`, `comment_id`, `x`, `y`, `p`, `cluster_ids`, `attributes`, `url` |
| `extract-clusters.js` | `report_clusters_YYYYMMDD_HHMM.tsv` | `level`, `id`, `parent`, `label`, `takeaway`, `value` |

- ファイル名の先頭は、各スクリプト冒頭の `PREFIX` で変更できます。
- TSV は BOM 付き UTF-8 です。Excel でもそのまま開けます。
- 本文中のタブと改行は半角スペースに置き換えています。
- `cluster_ids` は、レベル順にカンマ区切りで並んでいます（例: `0,1_3,2_1`）。
- 実行後、`window.__args` / `window.__clusters` に配列が残ります。JSON が必要な場合は、`copy(JSON.stringify(window.__args, null, 2))` でクリップボードにコピーできます。

### 各列の意味

**arguments**

| 列 | 内容 |
|---|---|
| `arg_id` | 意見の ID（例: `A1633_0`） |
| `argument` | 元のコメントから AI が抽出した意見の文 |
| `comment_id` | 元コメントの ID。声は番号そのまま、同様の声・返信は `1000000000 + コメント番号` |
| `x`, `y` | プロット上の座標 |
| `cluster_ids` | 所属クラスタ（レベル 0, 1, 2 …） |

元のコメントの原文は、レポートのデータには含まれていません。

**clusters**

| 列 | 内容 |
|---|---|
| `level` | 階層レベル（0 が全体） |
| `id` | クラスタ ID（arguments の `cluster_ids` と対応） |
| `parent` | 親クラスタの ID |
| `label` | クラスタ名 |
| `takeaway` | クラスタの説明文 |
| `value` | 含まれる意見の件数 |

### 1-3. みんなの声（声とコメント）を取得する

`extract-voices.js` は、arguments / clusters と違い、**公開ページ**で実行します。

1. 公開ページ（`https://maniken.jp/kikuai-open/<レポート名>/`）を開きます。
2. DevTools のコンソールに `scripts/extract-voices.js` の中身を貼り付けて実行します。
3. 「みんなの声」タブを 1 ページ目から順に読み込み、新しい声が出てこなくなったところで止まります。コンソールに `page 1: 50 voices` のような進み具合と、最後に `done: <声の件数> voices, <コメントの件数> comments` が表示されます。
4. 2 つの TSV がダウンロードされます。ブラウザから複数ファイルのダウンロードを許可するか聞かれたら、許可してください。

| 出力ファイル | 列 |
|---|---|
| `tagawa_all_voices_YYYYMMDD_HHMM.tsv` | `voice_id`, `date`, `who`, `genre`, `text`, `comment_count`, `page` |
| `tagawa_all_comments_YYYYMMDD_HHMM.tsv` | `comment_id`, `parent_voice_id`, `date`, `label`, `who`, `text` |

- ファイル名の末尾には、実行した日時（`YYYYMMDD_HHMM`）が付きます。2 つのファイルには同じ日時が付きます。
- ファイル名の先頭は `tagawa_all_` で固定です。他のレポートで使うときは、スクリプト末尾の `save(...)` のファイル名を書き換えてください。
- 並び順は新しい順（`sort=new`）です。開いているページの URL に `sort` が付いていれば、それに従います。
- arguments / clusters の TSV と形式が違います。BOM は付かず、改行は CRLF です。本文の改行はそのまま残し、タブ・改行・`"` を含む値は `"` で囲みます（Excel や Python の `csv` モジュールで読める形です）。

**各列の意味**

| ファイル | 列 | 内容 |
|---|---|---|
| voices | `voice_id` | 声の番号（arguments の `comment_id` の 4 桁の番号と対応） |
| voices | `comment_count` | 声に付いたコメントの件数（画面の表示から取得） |
| voices | `page` | 「みんなの声」の何ページ目にあったか |
| comments | `comment_id` | コメントの番号（arguments の `comment_id` では `1000000000 + 番号`） |
| comments | `parent_voice_id` | コメントが付いている声の `voice_id` |

## 2. Chrome 拡張（みんなの声ビューア）

「みんなの声」タブの各声・コメントの右側に、arguments TSV の対応する行（抽出された意見、`cluster_ids`、座標）を表示します。clusters TSV も取り込むと、各意見の下に所属クラスタの見出しが表示されます。

### インストール（パッケージ化されていない拡張機能として読み込む）

Chrome ウェブストアでは公開していません。次の手順で読み込みます。

1. このリポジトリを clone するか、ZIP でダウンロードして展開します。
2. Chrome で `chrome://extensions` を開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、`extension/kikuai-args-viewer` フォルダを選びます。

更新したときは、`chrome://extensions` で拡張機能の再読み込みボタンを押してください。

### 使い方

1. 公開ページ（`https://maniken.jp/kikuai-open/<レポート名>/`）の「みんなの声」タブを開きます。
2. 画面左下のツールバーから、1-2 で取得した 2 つの TSV を取り込みます。
   - 「argument取込」: **arguments の TSV** を選びます（`arg_id`、`comment_id` 列が必要）。
   - 「cluster取込」: **clusters の TSV** を選びます（`id`、`label` 列が必要）。どちらを先に取り込んでもかまいません。
3. 各声・コメントの右側に、対応する意見が表示されます。
   - `arg_id` の番号と `comment_id` が一致しない行は、橙色で表示されます。
   - 該当する行がない場合は「TSV に該当する行なし」と表示されます。
   - clusters TSV を取り込んでいると、各意見の下に、所属クラスタ（レベル 1 と 2）の ID、見出し、件数が表示されます。見出しにマウスを乗せると説明文（`takeaway`）が出ます。クラスタ TSV に無い ID は「クラスタファイルに該当なし」と表示されます。
4. ツールバーには、取り込んだファイル名と行数が表示されます。
5. 取り込んだ TSV は、レポートごとにブラウザに保存されます。次回からは自動で表示されます。「解除」で 2 つとも保存を消して元の表示に戻ります。

### 権限

- `storage`: 取り込んだ 2 つの TSV をブラウザ内に保存するため
- 動作対象: `https://maniken.jp/kikuai-open/*` のみ

## 3. ブックマークレット（プロット上で意見を探してハイライト）

レポート本体のグラフ上で、条件に合う意見に印を付け、ページの下に一覧を表示します。散布図（全体図・詳細クラスタ・濃い意見）と、階層（ツリーマップ）の表示に対応しています。

### 登録

1. ブックマークを新しく作るか、既存のものを編集します。
2. URL 欄に `bookmarklet/reveal-points.js` の中身を、先頭の `javascript:` も含めて全部貼り付けます。

改行を含んだまま貼り付けてかまいません（Chrome は改行を詰めますが、そのままでも動くように書いてあります）。

### 使い方

1. 1-1 の手順で、**レポート本体のページ**（`https://kikuai.maniken.jp/<ID>?...`）を開きます。
2. ブックマークレットを実行すると、検索条件のポップアップが出ます。

   | 入力欄 | 一致のしかた |
   |---|---|
   | テキスト | 一部一致。散布図では点のホバーに出る文字列で、階層表示と「この表示には出ていない該当意見」では意見の本文と所属クラスタ名で探します |
   | `arg_id` | 一部一致。`1935, 1936` のようにカンマ区切りで複数入れると、どれかを含めば対象 |
   | `comment_id` | 一部一致 |

   - 空欄の項目は条件にしません。複数の欄に入れると、すべてを満たすものだけを表示します。
   - Enter で検索、Esc でキャンセルします。
   - 一部一致なので、`1935` は `A1000001935_0` のような ID にも一致します。
3. 結果は、ページの下に紫の枠で表示されます。一番上の「Clusters in results」に、ヒットした意見が属するクラスタを、レベル順に `[Lv1] 見出し (id: 1_6, 1件)` の形で並べます。その下の内容は、表示しているグラフの種類で変わります（下の「散布図の場合」「階層表示の場合」を参照）。
4. 検索したあとでグラフの表示（全体図・詳細クラスタ・濃い意見・階層など）を切り替えると、同じ条件で自動的に表示し直します。ブックマークレットをもう一度実行すると、前の実行の監視は止めてから新しい条件で始めます。

`comment_id` とクラスタの見出しは、`extract-arguments.js` / `extract-clusters.js` と同じ方法でページのデータから読んでいます。読めなかった場合、クラスタ欄には「clusters データが見つかりませんでした」と表示されます。

### 散布図の場合

- 条件に合う点にオレンジの丸が付きます。
- 「Tracked Points」に、点ごとに次の 4 行を表示します。

  ```
  Point 75 (Trace 16): arg_id: A1000000040_0, comment_id: 1000000040,
  text: <点のホバーに出るクラスタ名>
  Lv1: <見出し> (1_6), Lv2: <見出し> (2_7)
  <意見の本文>
  ```

  `text:` の行はグラフの点のデータ（`trace.text`）から、`Lv1` / `Lv2` はページに埋め込まれた clusters（`cluster_ids` を突き合わせたもの）から取っています。取得元が違うので、両方を表示しています。
- 点を持つトレースをすべて対象にします（線だけのトレースや塗りつぶしの範囲は除きます）。同じ意見が複数のトレースにあっても、`arg_id` で重複を除いて 1 回だけ表示します。
- 点を選ぶと、グラフ上の点に赤い丸、一覧の行に赤い枠が付きます。赤い丸は最初に数回点滅し、次の点を選ぶまで表示が続きます（グラフを拡大・移動しても付いてきます）。
  - 「Tracked Points」の行をクリックすると、グラフが画面の中央に来るまでスクロールして、その点を選びます。ページで `window.Plotly` が使える場合は、その点のホバー表示も開きます。
  - グラフ上の点をクリックすると、一覧の該当する行までスクロールして、その点を選びます。検索結果に入っていない点をクリックしたときは、何も変わりません。
- 詳細クラスタや濃い意見の表示では、一部のクラスタの点しか描かれません。条件に合うのにその表示に出ていない意見は、一覧の最後の「この表示には出ていない該当意見 (N件)」に、折りたたんだ形でまとめて表示します（クリックで開きます）。
- その表示に該当する点が 1 つも無いときは、「この表示には該当する点がありません。」と表示します。

### 階層表示（ツリーマップ）の場合

- 「Tracked Opinions (階層, N件)」に、条件に合う意見を、`arg_id`、`comment_id`、所属クラスタ（Lv1 / Lv2）、本文の順で表示します。階層表示ではページのデータ（arguments）から探すので、arguments が読めないときは検索できません。
- グラフのタイルに枠を付けます。
  - オレンジの枠: 条件に合う意見を含むクラスタと、条件に合う意見のタイル
  - 赤い枠: 選んだ意見と、その上位のクラスタ
- 一覧の行をクリックすると、グラフまでスクロールして、その意見と上位のクラスタに赤い枠を付けます。
- 条件に合う意見のタイルをクリックすると、一覧の該当する行までスクロールして選びます。タイルをクリックして下の階層に入るページ本来の動きは、そのまま使えます。
